# Dashboard

# 📊 Power BI Dashboards Repository

## 📌 Overview
This repository contains interactive **Power BI dashboards** created to analyze and visualize sales data.  
These dashboards help in understanding business performance through KPIs, trends, and category-wise insights.

---

## 🛠 Tools & Technologies Used
- **Power BI Desktop**
- **Power Query** (Data Cleaning & Transformation)
- **DAX** (Measures & Calculations)
- **Data Visualization & Dashboard Design**

---

## 📂 Dashboards Included

### 1️⃣ Sales Dashboard
📁 File: `Sales dataset.pbix`  
**Description:**  
This dashboard provides a detailed analysis of sales performance with key metrics and interactive visuals.

**Key Features:**
- Total Sales, Profit, Quantity KPIs
- Monthly / Yearly Sales Trends
- Category-wise & Product-wise Performance
- Region / Segment Analysis
- Interactive Filters & Slicers

---

### 2️⃣ Super Market Sales Dashboard
📁 File: `Super Market Sales Data.pbix`  
**Description:**  
This dashboard analyzes supermarket sales data and provides insights into customer behavior and product performance.

**Key Features:**
- Sales & Profit KPI Summary
- Branch-wise and City-wise Performance
- Customer Type Analysis (Member vs Normal)
- Payment Method Insights
- Product Category Sales Breakdown
- Monthly Trend Analysis with Filters

---

## 📈 Insights Provided
✔ Identifies top-performing products and categories  
✔ Tracks business growth trends over time  
✔ Helps compare branch-wise and region-wise sales  
✔ Supports decision-making using interactive reports  

---

## 🚀 How to Use
1. Download the `.pbix` files from this repository  
2. Open using **Power BI Desktop**  
3. Click **Refresh** (if dataset is connected)  
4. Use slicers/filters to explore insights
